# Project Charter

ContribReady serves maintainers and prospective contributors. It measures whether the repository communicates a viable path from unfamiliarity to a tested contribution. Success means findings are reproducible, limitations are visible, and maintainers know what to fix next.

The product remains local-first, deterministic, static, and TypeScript-based. It has one main source-of-truth repository, one reusable core package, and one independently deployable CLI package. GitHub integration is initially a CLI adapter.
