# Competitive Landscape

OpenSSF Scorecard evaluates software security health using security heuristics and scores; GitHub community health provides files and profile conventions; issue templates improve structured intake; contributor guides and onboarding research describe practices rather than delivering a deterministic audit.

ContribReady is deliberately narrower and different: it evaluates outsider contribution success across setup, testing, contribution workflow, and individual issue actionability. It does not claim a security score, code-quality score, popularity score, or maintainer-performance score. It consumes local evidence first and keeps GitHub retrieval optional.

Research links: [OpenSSF Scorecard](https://github.com/ossf/scorecard), [GitHub community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file), and [The Open Source Way onboarding guide](https://github.com/theopensourceway/guidebook/blob/main/growing-contributors/constructing-an-onboarding-experience.md).
