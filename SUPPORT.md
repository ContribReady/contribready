# Support

For usage, setup, or contributor questions, open an issue in the repository you are using: [product](https://github.com/ContribReady/contribready/issues/new), [Core](https://github.com/ContribReady/contribready-core/issues/new), or [CLI](https://github.com/ContribReady/contribready-cli/issues/new). Discussions are not enabled. Include the ContribReady version, repository, command, platform, and sanitized output.

Do not include credentials or private repository content. Report vulnerabilities privately using `SECURITY.md`, not a public issue or discussion.
